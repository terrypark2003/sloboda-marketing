# 홈페이지 메인 배너 3종 — v2 (PC·모바일 겹침 해결판)

> **v1의 문제**: 피사체를 화면 정중앙에 놓았더니, 문구가 PC에서는 좌측에·모바일에서는 중앙 크롭의 좌측에 얹히면서 피사체와 겹쳤습니다.
> **v2의 규칙**: 문구가 앉는 영역(이미지 기준 **x 650~1150, y 350~760**)은 디테일 없이 비우고, 피사체는 **x 1050~1330**(모바일 크롭 안 오른쪽)에 배치. 좌측은 부드러운 배경만.
> → PC에서는 좌측 문구가 깨끗하게 읽히고, 모바일에서도 문구는 왼쪽·피사체는 오른쪽으로 분리됩니다.
