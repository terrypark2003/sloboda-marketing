# 홈페이지 메인 배너 3종 (1920×1080)

> 자사몰 슬라이더는 **풀블리드**라 PC는 16:9 전체가, 모바일은 **가운데 세로 띠(대략 폭 40%)만** 보입니다.
> 그래서 3장 모두 **피사체를 가로 중앙에, 좌우는 무늬 없는 배경**으로 설계했습니다.
> PC에서는 좌측이 비어 문구가 읽히고, 모바일 중앙 크롭에서도 피사체가 온전히 들어옵니다.

## 왜 문구를 바꿔야 하는가

| 기존 표현 | 문제 |
|---|---|
| **재생** (지친 피부를 깨우는 강력한 재생 에너지) | 화장품에 쓸 수 없는 의약품 오인 표현. 와디즈 심사에서 이미 같은 사유로 지적받은 이력이 있어, 자사몰에 남으면 근거 자료가 됨 |
| **고농축** | 근거 없는 최상급 표현. 우리는 병풀잎수 500,000ppm이라는 실측치가 있으므로 숫자를 쓰는 편이 더 강하고 안전 |
| **강력한** | 효능 강조 과장 표현 |
| **Hydrating Serum** (#3) | 우리가 판매하지 않는 제품. 템플릿 기본값이 남아 있던 것 |
| **광채 / 투명하게 차오르는** (#3) | 미백 기능성 표현과 혼동될 소지 |

교체안은 **진정 · 보습 · 장벽 케어** 범위와 **검증된 수치**(자극지수 0.00, 병풀잎수 500,000ppm)만 사용했습니다.
0.00은 규정상 항상 **'일반·민감성 피부 이중 임상'** 과 함께 표기해야 합니다 — 서브 문구에 반영돼 있습니다.

## 제작 방식 / 한계

**#1·#2** — 승인된 제품컷(`제품컷_신규/p2_podium.png`, `p5_swatch.png`)을 그대로 사용했습니다. AI로 배너를 새로 뽑으면 제품 라벨 글자가 깨질 위험이 있어(과거 대표이미지에서 오타가 읽힌 사례) 원본을 손대지 않는 방식을 택했습니다. #1은 좌우 배경을 원본 배경색으로 확장하고 경계를 180px 페더로 blend, #2는 16:9로 크롭한 뒤 좌우 반전해 잎이 문구 자리를 덮지 않게 했습니다.

**#3** — 제품이 없는 성분 무드컷이라 라벨 위험이 없어 16:9 원본 비율(2752×1536)로 새로 생성한 뒤 1920×1080으로 축소했습니다.

**남은 한계** — #1·#2의 제품 라벨은 AI 생성 렌더라 초근접에서 보면 미세 글자가 정확하지 않습니다. 배너 크기(제품 폭 약 600px)에서는 판독되지 않지만, **실제 제품 사진이 있으면 그것으로 교체하는 것이 가장 좋습니다.** 사진을 주시면 같은 레이아웃으로 다시 조판해 드립니다.
